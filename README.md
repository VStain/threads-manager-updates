# Threads Manager

Приложение для работы с Threads: расписание, публикации и контроль аккаунтов в одном окне.

## Установка

Актуальная тестовая версия для Windows — [0.3.2](https://github.com/VStain/threads-manager-updates/releases/tag/v0.3.2). Скачайте файл `Threads-Manager-Setup-0.3.2.exe` из раздела **Assets** и запустите установку.

После установки программа проверяет наличие новой версии при запуске. Скачать и установить обновление можно только после подтверждения. Проверка вручную доступна внизу боковой панели. Настройки, рабочие данные и лицензия сохраняются при обновлении.

## Планы

LITE позволяет закрепить до двух профилей AdsPower. PRO увеличивает лимит до 50 профилей и активируется персональным файлом лицензии. Возможности приложения в обоих планах одинаковы.
